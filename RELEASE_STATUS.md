# Release status

The original project-authored files in this repository are licensed under MIT. This does not grant rights to upstream code, pretrained weights, datasets, or third-party packages.

- **License:** settled for original project-authored files. Third-party rights are listed in `THIRD_PARTY_NOTICES.md`; the FFA-Net commit identified by the experiment source has no explicit license grant, and the Restormer experiment-matched commit is non-commercial. These upstream files and weights are not redistributed here.
- **Upstream versions:** architecture-file hashes match the pinned DehazeFormer, Restormer, and FFA-Net reference commits in `UPSTREAM_VERSIONS.md`, and the license files at those references were checked. Historical training records did not preserve full checkout revisions, so the reference commits cannot prove every historical source tree. DehazeFormer is MIT; the experiment-matched Restormer commit is non-commercial; the FFA-Net reference has no explicit license grant. No upstream source or weight is redistributed.
- **Checkpoints:** hashes and evidence are summarized in `CHECKPOINT_PROVENANCE.md`. The official FFA OTS initializer was downloaded from the upstream README-linked Drive folder and byte-matched to the recorded SHA-256. The experiment owner confirms that the FFA epoch-50 extension base was fully fine-tuned from this OTS initializer; the original fine-tuning log is not preserved for independent audit. The owner confirms that the Restormer extension base was fully fine-tuned from the official image-deraining pretrained weight (`deraining.pth`); its initializer hash and original fine-tuning run record are not preserved for independent audit. The owner also confirms that the project-trained DehazeFormer checkpoint stopped at epoch 127 because its metrics had reached the fitting state considered sufficient at the time; the archived metric history is unavailable for independent verification, and full run metadata remains incomplete. Checkpoint binaries are excluded.
- **Dependencies:** exact AutoDL runtime and package inventories are archived under `environment/`; they expose conflicting Torch and overlapping OpenCV metadata. A resolver check found that OpenCV 4.12.0.88 conflicts with the recorded NumPy 1.26.4 on Python 3.9, so the clean target now pins one compatible OpenCV distribution, 4.11.0.86. `environment.yml` and `requirements.txt` pin the runtime and direct dependencies, but no full transitive lock or fresh Linux install/smoke test is complete. Do not claim a fully reproducible environment yet.
- **Execution and data:** historical launch scripts still require external upstream source and checkpoint paths. Frozen split manifests, final-test assets, images, labels, and generated samples are excluded pending release and data-rights review.

This is a public source-code release with bounded execution evidence, not a complete reproduction package. One single-seed A0 adapter run completed for 40 epochs on AutoDL, and its source hashes match the released training files. This does not establish that all manuscript experiments or reported results have been reproduced. The dependency recipe is not a full transitive lock, and the run used external datasets, upstream source, and pretrained weights that are not included here. Users must obtain these assets under their own terms and provide substantial compute for some experiment arms.
